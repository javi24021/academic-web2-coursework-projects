## Getting Started

To run any individual project locally:

1. Clone the repository:
   git clone https://github.com/javi24021/academic-web2-coursework-projects.git

2. Navigate to the project directory:
   cd academic-web2-coursework-projects/apps/veterinaria-la-vaca-loca

3. Install dependencies and start the dev server:
   npm install
   npm run dev
